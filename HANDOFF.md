# Handoff: Instana Agent Installer

## Cilj
Alati za laku instalaciju/konfiguraciju Instana Host Agenta (korisnici + support inženjeri za repliciranje problema).
Scope v1: Linux host agent + Docker + Kubernetes (Helm). Operator, OpenShift i cloud = v2. Odgovaraj na srpskom, kratko.

## Fajlovi (Agent/)
- `agent-config-generator.html`: offline browser konfigurator (jedan fajl)
- `agent-triage.html`: offline browser dijagnostičar i analizator logova (jedan fajl)
- `agent-install.sh`: shell installer (`--dry-run`, `--config`, `--profile NAME`, `--status`, `--connectivity`, `--triage`, `--edit`, `--support-bundle`; env `INSTANA_AGENT_KEY` za neinteraktivno)
- `profiles/*.json`: ibm-mq, java-app, infrastructure-only, saas-eu-replica, saas-us-west (tenant je US West: `ingress-red-saas.instana.io`)
- Dizajn referenca: `skripta/instana-backend-skripta/config-generator.html`

## Stanje
- Multipass VM obrisan; aplikacija se uklanja ručno (`brew uninstall --cask multipass`).
- Test ide na GCP VM (Ubuntu 22.04, korisnik ga kreira ručno kroz Console i prenosi fajlove preko browser SSH upload-a).
- Dry-run i prava instalacija testirani na Debian 13 VM-u (vidi TODO 3).
- Ispravljeno u ovoj sesiji: `ask_secret` EOF petlja + `INSTANA_AGENT_KEY` env; resursi na Linuxu su systemd drop-in (`/etc/systemd/system/instana-agent.service.d/10-environment.conf`, `Environment=AGENT_MAX_MEM=...`) umesto `setenv`; "Disabled" updates zamenjen sa "Freeze" (pin version), jer `mode=MANUAL` nije u dokumentaciji.
