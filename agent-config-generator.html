MySQL Auto-discovered on localhost:3306. Needs a read-only user.

MySQL setup SQLCREATE USER 'instana'@'localhost' IDENTIFIED BY '<password>'; GRANT SELECT, PROCESS, REPLICATION CLIENT ON *.* TO 'instana'@'localhost'; FLUSH PRIVILEGES;

MariaDB Own sensor: the MySQL sensor does not monitor MariaDB.

MariaDB setup SQLCREATE USER 'instana'@'localhost' IDENTIFIED BY '<password>'; GRANT SELECT ON performance_schema.* TO 'instana'@'localhost'; GRANT SLAVE MONITOR ON *.* TO 'instana'@'localhost'; FLUSH PRIVILEGES;

PostgreSQL Auto-discovered on localhost:5432.

PostgreSQL setup SQLCREATE USER instana WITH PASSWORD '<password>'; CREATE DATABASE instana OWNER instana; GRANT CONNECT ON DATABASE instana TO instana; GRANT pg_monitor TO instana; -- PostgreSQL 10+

MongoDB Auto-discovered on localhost:27017.

mongosh commanduse admin db.createUser({ user: "instana", pwd: "<password>", roles: [ { role: "read", db: "admin" }, { role: "clusterMonitor", db: "admin" }, { role: "read", db: "local" } ] })

Redis Auto-discovered on localhost:6379.

Redis setup note# In redis.conf (if password protected): requirepass "<password>" # The CONFIG command must be reachable by the agent. # If it was renamed with rename-command, set config-command in configuration.yaml.

Elasticsearch Auto-discovered on localhost:9200. OpenSearch is not supported.

Microsoft SQL Server Local monitoring with SQL Server authentication.

Linux: DEFAULT. Windows: MSSQLSERVER or the named instance. A wrong name removes the sensor.
SQL Server setup SQLCREATE LOGIN instana WITH PASSWORD = '<password>'; CREATE USER instana FOR LOGIN instana; GRANT VIEW SERVER STATE TO instana; GRANT VIEW DATABASE STATE TO instana; -- For disk volume & auto-growth metrics, add sysadmin membership or db_owner.

IBM MQ One row per queue manager. Host only for a remote queue manager.

runmqsc authorizationSET AUTHREC OBJTYPE(QMGR) PRINCIPAL('<user>') AUTHADD(CONNECT,DSP,INQ) SET AUTHREC PROFILE('SYSTEM.ADMIN.COMMAND.QUEUE') OBJTYPE(QUEUE) PRINCIPAL('<user>') AUTHADD(DSP,INQ,PUT,CHG) SET AUTHREC PROFILE('SYSTEM.DEFAULT.MODEL.QUEUE') OBJTYPE(QUEUE) PRINCIPAL('<user>') AUTHADD(DSP,GET) SET AUTHREC PROFILE('SYSTEM.ADMIN.STATISTICS.QUEUE') OBJTYPE(QUEUE) PRINCIPAL('<user>') AUTHADD(DSP,INQ,GET,CHG) SET AUTHREC PROFILE('**') OBJTYPE(QUEUE) PRINCIPAL('<user>') AUTHADD(DSP,INQ,GET,CHG) SET AUTHREC PROFILE('**') OBJTYPE(CHANNEL) PRINCIPAL('<user>') AUTHADD(DSP) SET AUTHREC PROFILE('**') OBJTYPE(CLNTCONN) PRINCIPAL('<user>') AUTHADD(DSP) SET AUTHREC PROFILE('**') OBJTYPE(LISTENER) PRINCIPAL('<user>') AUTHADD(DSP) SET AUTHREC PROFILE('**') OBJTYPE(TOPIC) PRINCIPAL('<user>') AUTHADD(DSP) REFRESH SECURITY
